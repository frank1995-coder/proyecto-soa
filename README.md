# Arquitectura SOA — Centro Hospitalario Universitario

Implementación de una arquitectura orientada a servicios (SOA) para un centro hospitalario, integrando sistemas aislados de Autenticación, Pacientes, Historias Clínicas y Laboratorio mediante un **ESB/API Gateway**.

## Stack Tecnológico

- **Backend:** Node.js v24 · Express · node-soap · node-postgres
- **Base de Datos:** PostgreSQL 17 (Docker)
- **Protocolos:** REST/JSON · SOAP/XML (WSDL)
- **Entorno:** Windows 11 · PowerShell · Docker Desktop · Postman
